# Newsletter Editor

A visual drag-and-drop editor for building HTML email newsletters. Runs entirely in the browser — no backend required.

## Features

- **Block-based editing** — header, text, heading, image, two-column, event, quote, button, divider, spacer, footer
- **Drag & drop** reordering of blocks
- **Image upload** via file picker or drag & drop (converted to base64)
- **Image cropping** — adjustable crop height with vertical position control
- **Inline icon insertion** from the Phosphor icon library
- **Outlook-compatible export** — generates table-based HTML with inline styles
- **Export options** — preview in new tab, copy HTML to clipboard, or download as `.html` file

## Usage

Open `index.html` in a browser. Add blocks from the sidebar, edit content inline, and export when ready.

## Tech

Plain HTML, CSS, and vanilla JavaScript. No build step, no dependencies (icons loaded from CDN).
